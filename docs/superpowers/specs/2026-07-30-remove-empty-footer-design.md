# Remove Empty Footer Design

Date: 2026-07-30

## Goal

Remove the empty gray bar and its spacing from the bottom of every website
page without disabling MathJax, Mermaid, or the site's main JavaScript.

## Design

The gray bar is generated by the `.page__footer` wrapper in the site's two
top-level layouts:

- `_layouts/default.html`
- `_layouts/cv-layout.html`

The visible footer content is already intentionally blank. The wrapper still
receives background color, top border, margins, and padding from
`_sass/layout/_footer.scss`, which creates the unwanted bar.

Remove the `.page__footer` and nested `<footer>` elements from both layouts.
Keep `{% include footer/custom.html %}` at the bottom of `<body>`, immediately
before `{% include scripts.html %}`. This preserves the MathJax and Mermaid
script tags currently stored in the custom footer include.

Do not use a CSS override. Removing the unused structural markup avoids leaving
an invisible footer and unnecessary spacing in the document.

## Scope and constraints

- Apply the change to standard pages and the CV layout.
- Preserve `_includes/footer/custom.html` and its MathJax and Mermaid behavior.
- Preserve `{% include scripts.html %}`.
- Do not modify theme colors or footer Sass.
- Do not add replacement footer content.
- Do not modify or commit the unrelated `.DS_Store` working-tree change.

## Validation

- A Jekyll build completes successfully.
- Rendered homepage, Publications, Projects, and CV pages contain no
  `page__footer` element.
- Rendered pages still include MathJax, Mermaid, and the main JavaScript bundle.
- Existing page content and navigation remain present.
- `.DS_Store` remains unstaged and uncommitted.
