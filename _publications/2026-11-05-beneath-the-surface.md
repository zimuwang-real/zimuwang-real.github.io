We evaluated four agent evolution methods to see which tasks agents gained or lost, how much they cost to run, and how well changes transferred to other benchmarks. Every evolved agent gained new tasks and lost some it had previously solved. We used these findings to revise how evolution methods select agents, propose changes, and admit candidates.
