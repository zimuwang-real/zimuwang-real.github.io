Accepted at the [NeurIPS 2026 Meta-Agents Workshop](https://meta-agents-workshop.github.io/).

RSIHub provides a composable framework for agent self-improvement that evolves prompts, skills, harnesses, and code while preserving fixed evaluators, declared mutation boundaries, and auditable Git-based experiment lineage.

Code is available on [GitHub](https://github.com/simple-agent-lab/RSIHub).
