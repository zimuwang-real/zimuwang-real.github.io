Project 2 | Signal Processing for Vision

Filtering, frequencies, hybrid perception, and pyramid blending

This page groups several related image-processing tasks. The common theme is that filtering changes the visual information in an image in predictable ways, and those changes can be used for edge detection, sharpening, hybrid perception, and seamless image blending.

Theme How filtering changes what image structure is visible
Methods Convolution, frequency separation, FFT inspection, Gaussian and Laplacian pyramids
Output Edges, sharpened images, hybrid images, and seamless composites

Questions on this page

  • Explain what image filters do beyond just showing the final image.
  • Show how low-frequency and high-frequency content affect perception.
  • Blend separate images without a visible hard seam.

Main ideas

  • Finite-difference filters and gradient magnitude maps.
  • Unsharp masking through high-frequency residual addition.
  • Hybrid images built from aligned low-pass and high-pass components.
  • Gaussian and Laplacian pyramids for multi-scale blending.

Edge detection

Finite-difference filters respond to intensity changes, so they highlight boundaries and other high-frequency structure.

Sharpening

Blurring removes high frequencies. Subtracting the blur from the original image isolates those details, and adding them back produces an unsharp mask.

Hybrid perception

A low-pass image dominates at a distance, while a high-pass image dominates nearby. Combining them creates a single image with two interpretations at different scales.

Implementation Notes

What changes mathematically from section to section

Derivatives and smoothing

Edge maps are built from local intensity differences, often after smoothing to suppress noise. The combination gives cleaner structure than raw finite differences alone.

Frequency separation

Hybrid images are built by low-pass filtering one source and high-pass filtering another. FFT visualizations are included to show that the spectrum really is being split as intended.

Multi-scale blending

The blending stage constructs Gaussian and Laplacian pyramids so coarse structure and fine detail can be mixed with different masks at different scales, which removes the hard seam of naive cut-and-paste compositing.
