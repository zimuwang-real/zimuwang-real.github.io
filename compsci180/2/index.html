Project 1 | Image Alignment and Color Reconstruction

Recovering color from misaligned glass-plate negatives

Each source file is a single grayscale image that actually contains three exposures of the same scene: one for blue, one for green, and one for red. The task is to split that stacked scan into three channels, align the channels, and combine them into a single color reconstruction.

Input One vertically stacked grayscale scan containing blue, green, and red exposures
Core method Translation search on edge images with coarse-to-fine refinement
Outcome Aligned archival color reconstructions

What makes the task hard

  • The three channel exposures are shifted relative to each other.
  • Naive recombination creates color fringes and blurred edges.
  • High-resolution scans make brute-force alignment expensive.

Pipeline

  • Split the stacked plate into separate channels.
  • Measure alignment quality on edge structure instead of raw intensity.
  • Search for the best translation with normalized correlation.
  • Use image pyramids so alignment remains practical on large scans.
What The Reader Is Looking At

Input and output of the reconstruction pipeline

The source material is not a color image. It is a single stacked scan of three monochrome exposures. The pipeline first separates those exposures, then aligns them, then merges them into one RGB image.

Reconstruction Flow

Channel split

The input image is divided into three equal-height slices. Those slices become the blue, green, and red channels of the final image.

Alignment target

Blue is used as the reference channel. Green and red are shifted until strong structures, especially edges, line up with the blue channel.

Final composition

Once the best shifts are found, the channels are stacked into RGB order and the unstable border is cropped away.

Implementation Notes

What makes the alignment reliable

Edge-based matching

The implementation builds Sobel edge maps for each pyramid level and compares those instead of raw intensities, which makes the search less sensitive to exposure differences between channels.

Normalized correlation

Before scoring a candidate shift, the cropped patches are normalized by mean and standard deviation. This keeps the score focused on structure rather than brightness.

Coarse-to-fine search

The image pyramid is built with Gaussian smoothing and downsampling. A rough shift is found on the smallest image, doubled at each finer level, and refined locally.

Key point

This project is a compact example of image registration: the output quality depends less on complex modeling than on careful similarity scoring, stable borders, and multi-scale search.
