Project 3 | Geometric Vision

Manual and automatic panorama stitching

The goal is to take multiple overlapping photos of the same scene and combine them into a single wider image. This requires estimating how one image maps into another, first with manual correspondences and then with an automatic feature-matching pipeline.

Input Overlapping photos of the same scene taken from slightly different positions
Methods Homography estimation, Harris corners, descriptors, nearest-neighbor matching, RANSAC
Output Perspective rectification and stitched panoramas on a shared canvas

What must be estimated

  • Two images overlap but do not share the same pixel coordinates.
  • A panorama requires warping one image into the coordinate system of another.
  • Automatic matching must handle bad correspondences and outliers.

Pipeline

  • Estimate homographies from matched points.
  • Warp images into a shared reference frame.
  • Detect Harris corners and reduce redundancy with ANMS.
  • Match descriptors and reject outliers with RANSAC.
What The Warp Does

From point correspondences to a stitched panorama

Homography

A homography is a projective mapping between two views of the same plane. Once it is estimated, one image can be resampled into the coordinate system of the other.

Rectification

The same math can also remove perspective distortion. Mapping a photographed rectangle back to a front-facing view is a good way to verify that the warp behaves correctly.

Robust stitching

In the automatic pipeline, feature matches include outliers. RANSAC repeatedly fits candidate homographies and keeps the one supported by the largest consistent set of matches.

Direct homography solve Projective mapping from matched points 
def solve_h(img1_pts, img2_pts):
    A_rows, b_rows = [], []
    for (x, y), (u, v) in zip(img1_pts, img2_pts):
        A_rows += [[x, y, 1, 0, 0, 0, -u*x, -u*y],
                   [0, 0, 0, x, y, 1, -v*x, -v*y]]
        b_rows += [u, v]

    A = np.asarray(A_rows, dtype=np.float64)
    b = np.asarray(b_rows, dtype=np.float64)
    h8 = np.linalg.solve(A, b)
    return np.append(h8, 1.0).reshape(3, 3)
Corner detection with edge rejection Practical filtering before matching 
def get_harris_corners(im, edge_discard=20,
                       min_dist=10, threshold=0.01):
    h = corner_harris(im, method='eps', sigma=1)
    coords = peak_local_max(
        h, min_distance=min_dist, threshold_abs=threshold
    )

    mask = ((coords[:, 0] > edge_discard) &
            (coords[:, 0] < im.shape[0] - edge_discard) &
            (coords[:, 1] > edge_discard) &
            (coords[:, 1] < im.shape[1] - edge_discard))
    return h, coords[mask].T
Manual Geometry

Start with trusted correspondences, then validate the warp

The first stage uses manually selected point pairs. This isolates the geometric part of the problem before moving to automatic feature detection and matching.

Rectification

Homographies can also normalize perspective

A rectified result should look as if the camera were facing the surface head-on. This is a useful sanity check for the estimated transformation and the resampling code.

Key point

The main engineering challenge is not the final warp itself. It is getting reliable correspondences and rejecting the bad ones before solving for the homography.
