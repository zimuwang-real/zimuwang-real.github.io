Project 5 | Generative Vision

Diffusion workflows and UNet-based generative modeling

This page covers two related generative-modeling tasks. Part A studies how a pretrained diffusion model can denoise, edit, and complete images. Part B trains simplified UNet-based generative models from scratch so the sampling process and conditioning logic are explicit rather than hidden behind a library.

Part A Pretrained diffusion for denoising, editing, inpainting, and guided sampling
Part B Time-conditioned and class-conditioned UNets trained from scratch on MNIST
Output Denoising comparisons, edited images, training curves, and generated samples

Questions on this page

  • Understand how iterative denoising turns noise into a plausible image.
  • Control the output with prompts, masks, time conditioning, or class labels.
  • Compare pretrained generation with directly trained UNet models.

Pipeline

  • Forward noising and iterative denoising analysis.
  • Classifier-free guidance, image-to-image translation, and inpainting.
  • Time-conditioned UNet training and sampling.
  • Class-conditioned UNet training with improved sample controllability.
How To Read This Page

Two views of the same generative process

Part A: use a pretrained model

The first half treats a diffusion model as an image prior and studies what it can do at inference time: denoising, prompt guidance, inpainting, and controlled image transformation.

Part B: train the model directly

The second half removes the black box by training smaller UNet-based models from scratch, so the effects of timestep conditioning and class conditioning are visible in the loss curves and samples.

Shared idea

Both halves rely on the same basic loop: start from noise or a noisy image, predict how it should change, and repeat that update over many steps until structure appears.

Time-conditioned flow matching Sample random times and regress the transport direction 
def time_fm_forward(unet, x_1, num_ts):
    x_0 = torch.randn_like(x_1)
    ground_truth = x_1 - x_0

    t_list = torch.randint(0, num_ts, (x_1.shape[0],),
                           device=x_1.device)
    t = t_list.float() / (num_ts - 1)
    t_shaped = t.view(-1, 1, 1, 1)
    x_t = (1 - t_shaped) * x_0 + t_shaped * x_1
    pred = unet(x_t, t)
    return nn.MSELoss()(pred, ground_truth)
Class-conditioned sampling with guidance Iteratively refine from noise using conditional control 
def class_fm_sample(unet, c, img_wh, num_ts,
                    guidance_scale=5.0, seed=0):
    torch.manual_seed(seed)
    H, W = img_wh
    x_t = torch.randn(c.shape[0], 1, H, W,
                      device=next(unet.parameters()).device)
    dt = 1.0 / num_ts
    for t_step in range(num_ts):
        t = torch.full((c.shape[0],), t_step / num_ts,
                       device=x_t.device)
        pred_cond = unet(x_t, c, t)
        pred_uncond = unet(x_t, c, t, torch.zeros_like(c))
        pred = pred_uncond + guidance_scale * (pred_cond - pred_uncond)
        x_t = x_t + pred * dt
    return x_t
